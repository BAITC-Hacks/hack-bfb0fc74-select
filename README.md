# Select — умный подбор подрядчиков

Select помогает заказчику выбрать до трёх event-подрядчиков из каталога своего города для конкретного мероприятия. Система проверяет дату, формат, бюджет и необязательные условия, затем объясняет выбор каждого профиля. Это решение кейса #79-lite трека 06 HackAlem AI.

## Что реализовано

- Форма с городом, датой, типом мероприятия, категорией и бюджетом в тенге. Длительность и язык работы необязательны.
- Проверка занятости на дату, в том числе у площадок; строгая проверка остальных условий и повторяемый порядок выдачи.
- До трёх карточек с конкретными объяснениями. Если подходящих меньше трёх, указаны причины отсева.
- Отдельные сообщения для города без выбранной категории и для случая, когда категория есть, но все профили отсеяны условиями.
- После смены только даты интерфейс сравнивает выдачу и показывает, кто был занят на прежнюю или новую дату.
- Локальные объяснения без API-ключа. Если задан `OPENAI_API_KEY`, можно включить AI для выбора подходящего дословного фрагмента описания. Если API недоступен или вернул неверные данные, используются локальные объяснения.
- Пометки синтетических профилей, а также городов и цен, заполненных при подготовке набора данных.

## Установка и запуск

Нужен Python 3.11 или новее. Первый раз для установки зависимостей нужен интернет. API-ключ для основного сценария не нужен.

macOS / Linux:

```bash
python3 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
./.venv/bin/python -m streamlit run app.py
```

Windows PowerShell:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Streamlit покажет локальный адрес приложения в терминале. Установка создаёт файлы только в `.venv`, который исключён из Git.

Для AI-режима дополнительно установите `requirements-ai.txt` тем же способом, что и основные зависимости, и задайте `OPENAI_API_KEY` в окружении или локальном файле `.env` в корне проекта. Этот файл исключён из Git; не добавляйте ключ в отслеживаемые файлы. Переменная окружения имеет приоритет. Модель можно выбрать через `OPENAI_MODEL`; по умолчанию используется `gpt-4.1-mini`. Наличие кредитов не гарантирует доступ к каждой модели. Если ключа нет, приложение показывает проверяемые локальные объяснения и все сценарии работают.

## Как проверить за несколько минут

Поля ниже доступны в форме. Для наглядного сравнения дат отправляйте первые два запроса в одной вкладке; меняйте только дату.

| Сценарий | Город | Дата | Тип | Категория | Бюджет |
| --- | --- | --- | --- | --- | ---: |
| Плотная категория | Алматы | 10.10.2026 | свадьба | Ведущий | 2 000 000 ₸ |
| Смена даты | Алматы | 11.10.2026 | свадьба | Ведущий | 2 000 000 ₸ |
| Редкая категория | Алматы | 10.10.2026 | свадьба | Флорист | 300 000 ₸ |
| Нет категории в городе | Астана | 10.10.2026 | свадьба | Декоратор | 3 000 000 ₸ |
| Категория есть, кандидатов нет | Алматы | 10.10.2026 | свадьба | Ведущий | 100 000 ₸ |
| Площадка | Алматы | 14.11.2026 | свадьба | Банкетный зал | 6 000 000 ₸ |

Без языка и длительности первый запрос даёт три допустимых профиля, второй — пять до ограничения выдачи тройкой. Итоговая тройка меняется; сравнение указывает, что добавившиеся профили были заняты на первую дату. Запрос на флориста даёт одну карточку; два пустых запроса показывают разные сообщения.

Повторите любой запрос: порядок карточек останется прежним. Для проверки ограничений задайте язык и длительность. `max_hours` отсутствует у флористов, декораторов и сувениров, поскольку их работа не привязана к часам присутствия на площадке.

## Как устроено решение

Точные границы MVP и интерфейс между модулями зафиксированы в [MVP_CONTRACT.md](MVP_CONTRACT.md).

`app.py` читает запрос и показывает результат. `matcher.py` загружает `data/contractors.csv`, проверяет схему и календарь, затем отбирает профили. Город и категория должны совпадать точно. Среди профилей этой категории последовательно проверяются занятость, начальная цена, формат, указанные язык и длительность. Каждый исключённый профиль учитывается один раз — по первой причине в этом порядке. Пустое `max_hours` не является ограничением.

Прошедшие профили упорядочиваются по наличию упоминания выбранного формата в описании, затем по меньшей начальной цене и ID. Это прозрачная эвристика для выбора из каталога, а не рейтинг качества подрядчиков. Ответ обрезается до трёх карточек; одинаковый запрос всегда даёт один порядок.

`explanations.py` составляет предложение из проверенных полей и добавляет конкретный фрагмент описания. Если включён AI, один запрос к OpenAI предлагает выбрать номер одного из максимум четырёх заранее проверенных дословных фрагментов для каждой отобранной карточки. Приложение проверяет число карточек, ID, порядок и номер варианта, а текст объяснения собирает локально из исходного CSV. AI не может изменить отбор или добавить сведения о цене, занятости либо формате. При ошибке API или неверном ответе включается локальный режим. Интерфейс показывает, какой режим использован.

AI по умолчанию выключен. При его включении в OpenAI отправляются ID, категория, формат мероприятия, указанный язык и до четырёх коротких фрагментов описания для каждого из максимум трёх выбранных профилей. Фрагменты с именем подрядчика, ценой или датой исключаются до отправки. Поле имени, цена, выбранная дата, календарь занятости и весь CSV не отправляются. Без ключа или при выключенном AI запрос к внешнему сервису не выполняется.

Для разработки решения использовались AI-агенты Codex: отдельные задачи по подбору, объяснениям и интерфейсу, с общей интеграцией и проверкой. Само приложение работает одним локальным процессом; агентный сервис при запуске не требуется.

## Данные и ограничения

`data/contractors.csv` — предоставленный организаторами анонимизированный набор из 66 профилей и 13 полей. Есть 13 полностью синтетических профилей; у части остальных при подготовке данных заполнены город или цена. Категории могут быть множественными. Даты занятости известны только с 23.09 по 31.12.2026 включительно. Приложение не принимает дату вне этого окна как подтверждённо свободную.

`price_from_kzt` означает цену **от** за мероприятие: попадание в бюджет не гарантирует итоговую стоимость. Описания иногда содержат дополнительные заявления, отсутствующие в структурированных полях; допуск к выдаче определяется структурированными полями. Упоминание работы в другом городе само по себе не даёт подтверждённого тарифа выезда. Нет бронирования, заявок, уведомлений, дополнительного каталога или дообученной модели.

## Возможное развитие

Разделение строгой проверки условий и объяснения выбора позволяет расширять каталог без дообучения на 66 строках: новые профили проходят тот же контракт и остаются проверяемыми. Следующий шаг после MVP — экспертная оценка полезности объяснений на наборе типовых запросов; сейчас такой разметки нет. Механизм сравнения дат можно применять к более широкому календарю, когда появятся подтверждённые данные о доступности.

## Автоматические проверки

```bash
./.venv/bin/python -m pip install -r requirements-dev.txt
./.venv/bin/python -m pytest -q
```

В Windows замените путь к интерпретатору на `.\.venv\Scripts\python.exe`. Проверки охватывают CSV, календарь, строгий отбор, редкие и пустые результаты, смену даты, повторяемость порядка и резервные объяснения.

На демонстрационной тройке 11.10.2026 обновлённый AI-режим также проверен одним живым запросом: ответ прошёл проверку ID, дословности и различимости фрагментов за 2,73 секунды. Время API на другом компьютере и соединении может отличаться.
